## 3. 요구사항 정의

### 2-1. 공지 게시판
- **권한**
  - 인사팀 : 작성/수정/삭제 가능
  - 일반 회원 : 목록 조회 / 상세 조회 가능
- **기능**
  1. 공지 등록 : 제목, 내용, 첨부파일, 에디터 이미지 업로드
  2. 공지 수정/삭제 : 인사팀 소속 관리자만 가능
  3. 공지 목록 조회 : 복합검색 + 페이징
     - 검색 조건 : 제목, 내용, 작성자, 공지 유형(태그)
  5. **공지 상세 조회** : 공지 본문 + 첨부파일 + 작성자 정보 함께 표시
- **특징**
  - 첨부파일과 에디터 이미지를 **별도 테이블**로 분리 저장  
  - 일반 첨부파일과 본문 삽입 이미지를 구분 관리하기 위함

### 2-2. 일정 관리
- **사용자** : 모든 회원
- **기능**
  1. 일정 등록 : 
    - 개인 일정은 개인 전용 화면에서 등록
    - 팀/전체 일정은 공유 화면에서 등록
    - 전체 일정은 개인 + 공유 일정을 함께 표시
    - 입력 항목: 제목, 내용, 시작일, 종료일, 종일 여부, 일정 표시 색상
    - 공유 일정의 경우 참여자 선택 UI 제공 (검색 가능, 본인 제외 처리)
  2. 일정 목록 조회 :
    - FullCalendar에 모든 일정 표시 (개인/팀/전체 일정 색상 및 태그 구분)
    - 날짜(빈 공간) 클릭 시 -> 해당 날짜에 포함된 모든 일정을 **리스트 모달**로 표시
    - 일정(바) 클릭 시 -> 선택한 일정을 **상세 모달**로 표시
  3. 일정 상세 조회 :
    - 캘린더에서 특정 일정을 클릭하면 모달 팝업 표시
    - 모달에서 제목, 내용, 일정 기간, 참여자 목록, 달성 상태 등 확인 가능
  4. 일정 수락/거절 : 
    - 수신자는 초대된 일정을 수락하거나 거절
  3. 일정 달성 상태 변경 :
    - 일정 참여자는 자신의 일정 달성 상태를 달성/미달성으로 변경 가능 (토글 방식)
  4. 일정 삭제 :
    - 일정 초대자가 일정 삭제 시 모든 참여자에게 반영
- **특징**
  - FullCalendar 기반 React 연동
  - 작성자도 참여자로 포함하여 관리
  - 모든 참여자가 달성 시 일정 상태가 **(완료)**로 표시됨

### 2-3. 알림
- **사용자**: 모든 회원
- **기능**
  1. 일정 생성 시 -> 수신자에게 알림 전송 (수락/거절 버튼 + 상세보기 버튼 포함)
     - 수락/거절 : 알림 화면에서 바로 응답 가능
     - 일정 상세 조회 : 버튼 클릭 시 해당 일정의 **상세 모달** 팝업
  2. 일정 수락/거절 시 -> 작성자에게 알림 전송
  3. 일정 완료/삭제 시 -> 모든 참여자에게 알림 전송
  4. 일정 시작 시간 30분 전 / 시작 시 / 종료 시 -> 모든 참여자에게 알림 전송
  5. 알림 읽음 처리
     - 알림 클릭 시 읽음 처리
     - 메뉴 탭의 알림 개수에서 자동 차감
  6. 무한 스크롤 기반 알림 목록 조회 지원

- **특징**
  - WebSocket + DB 저장 동시 처리
